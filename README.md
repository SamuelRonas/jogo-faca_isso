# Faça Isso

**Faça Isso** é um jogo de navegador desenvolvido com **Vite**, com o objetivo de ensinar **lógica de programação** de forma intuitiva e divertida.

Neste jogo, os jogadores precisam criar **sequências de passos** para resolver desafios e executar ações. A proposta é apresentar os conceitos básicos de programação de maneira simples, por meio de problemas que incentivam o raciocínio lógico e a tomada de decisão.

## 🚀 Funcionalidades principais

- Criar sequências de passos para resolver desafios.
- Introduzir conceitos como:
  - Sequências de comandos.
  - Estruturas de decisão (if/else).
  - Laços de repetição (for, while).
  - Funções e blocos de código.
- Jogabilidade simples e interativa.
- Interface amigável para iniciantes.

## 💻 Tecnologias

- [Vite](https://vitejs.dev/) – Build tool para desenvolvimento rápido.
- HTML, CSS e JavaScript (puro ou com frameworks/libraries a definir).

## 📌 Objetivo

O projeto tem como meta tornar o aprendizado de lógica de programação **acessível**, **intuitivo** e **divertido**, estimulando a curiosidade e o pensamento crítico.
